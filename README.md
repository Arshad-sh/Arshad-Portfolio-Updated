## 💻 Run Locally

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Arshad-sh/Arshad-Portfolio-Updated.git
   ```

2. Navigate into the project directory:

   ```bash
   cd Arshad-Portfolio-Updated
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## 📦 Build for Production

```bash
npm run build
```

The production-ready files will be generated in the `dist` directory.

## 🚀 Deployment

This project can be deployed using [Vercel](https://vercel.com/).

Connect the GitHub repository to Vercel and configure the project using the Vite build settings.
